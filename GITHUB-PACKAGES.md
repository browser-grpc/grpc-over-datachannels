# GitHub Packages mirrors\n\nThe canonical packages live on the language registries\n(npm, PyPI, Maven Central + the Pages Maven repo, NuGet,\ncrates.io-compatible git tags for Go). As a mirror, the\nregistries GitHub Packages can host are also published\nto GitHub under the `browser-grpc` org at each release:\n\n| Ecosystem | GitHub Packages artifact |\n|---|---|\n| npm | `@browser-grpc/grpc-dc` |\n| NuGet | `GrpcDc` |\n| RubyGems | `grpc-dc` |\n\nEach ecosystem also gets a separate `kafka-grpc` package\n(npm `@browser-grpc/kafka-grpc`, NuGet `KafkaGrpc`, gem\n`kafka-grpc`) holding the generated `grpcdc.kafka.v1`\nstubs; see packages/README.md in the export.\n\nGitHub Packages requires an authenticated token for\nconsumers **even for public packages** (a GitHub personal\naccess token with `read:packages`). That friction is why\nMaven is *not* mirrored here: the Pages-hosted Maven repo\n(see MAVEN-PUBLISHING.md) resolves the same coordinates\nanonymously. Ecosystems GitHub cannot host (Python, Rust,\nGo, Dart, PHP, Lua, Swift, Zig, C/C++) use their language\nregistries, git tags, or the release zip instead.\n\n## npm\n\n```ini\n@browser-grpc:registry=https://npm.pkg.github.com\n//npm.pkg.github.com/:_authToken=YOUR_TOKEN\n```\n\n## NuGet\n\n```sh\ndotnet nuget add source https://nuget.pkg.github.com/browser-grpc/index.json \\\n  --name github-browser-grpc --username YOUR_GITHUB_USER --password YOUR_TOKEN\ndotnet add package GrpcDc\n```\n\n## RubyGems\n\n```sh\ngem install grpc-dc \\\n  --source https://rubygems.pkg.github.com/browser-grpc/\n```\n(with `github: Bearer YOUR_TOKEN` in ~/.gem/credentials)\n
