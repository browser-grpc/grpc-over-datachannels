# GitHub Packages mirrors\n\nThe canonical packages live on the language registries\n(npm, PyPI, Maven Central + the Pages Maven repo, NuGet,\ncrates.io, pub.dev, and git tags for Go). As a mirror, the\nregistries GitHub Packages can host are also published\nto GitHub under the `browser-grpc` org at each release:\n\n| Ecosystem | GitHub Packages artifacts |\n|---|---|\n| npm | `@browser-grpc/grpc-dc`, `@browser-grpc/kafka-grpc`, `@browser-grpc/eventbus-grpc` |\n| NuGet | `GrpcDc`, `KafkaGrpc`, `EventBusGrpc` |\n| RubyGems | `grpc-dc`, `kafka-grpc`, `eventbus-grpc` |\n\nEach ecosystem also gets separate `kafka-grpc` and\n`eventbus-grpc` packages (npm `@browser-grpc/kafka-grpc`\nand `@browser-grpc/eventbus-grpc`, NuGet `KafkaGrpc` and\n`EventBusGrpc`, gems `kafka-grpc` and `eventbus-grpc`)\nholding the generated Kafka and event-bus stubs; see\npackages/README.md in the export. NuGet and RubyGems\nmirrors are pushed from the packed artifacts by\nscripts/release-push.sh and need `dotnet`/`gem` on the\npublishing host (the CI image has both).\n\nGitHub Packages requires an authenticated token for\nconsumers **even for public packages** (a GitHub personal\naccess token with `read:packages`). That friction is why\nMaven is *not* mirrored here: the Pages-hosted Maven repo\n(see MAVEN-PUBLISHING.md) resolves the same coordinates\nanonymously. Ecosystems GitHub cannot host (Python, Rust,\nGo, Dart, PHP, Lua, Swift, Zig, C/C++) use their language\nregistries, git tags, or the release zip instead.\n\n## npm\n\n```ini\n@browser-grpc:registry=https://npm.pkg.github.com\n//npm.pkg.github.com/:_authToken=YOUR_TOKEN\n```\n\n## NuGet\n\n```sh\ndotnet nuget add source https://nuget.pkg.github.com/browser-grpc/index.json \\\n  --name github-browser-grpc --username YOUR_GITHUB_USER --password YOUR_TOKEN\ndotnet add package GrpcDc\n```\n\n## RubyGems\n\n```sh\ngem install grpc-dc \\\n  --source https://rubygems.pkg.github.com/browser-grpc/\n```\n(with `github: Bearer YOUR_TOKEN` in ~/.gem/credentials)\n
