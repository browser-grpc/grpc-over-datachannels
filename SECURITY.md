# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability.

Report it privately through GitHub's private vulnerability reporting on the affected repository (Security → Report a vulnerability) in the `browser-grpc` org, or by email to jdavis@pcprogramming.com.

Include what you found, how to reproduce it, and the affected version. You will get an acknowledgement, and a fix or mitigation plan will follow once the report is confirmed.

## Supported versions

The latest release of each package is supported. Generated packages are versioned together; fixes land in the next release and are noted in the changelog.
