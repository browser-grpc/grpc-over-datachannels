VoxelSeed

A tiny Minecraft-style voxel world, procedurally generated from a seed and multiplayer over grpc-dc: gRPC on a WebRTC DataChannel. The session host's browser is the server — friends join from a link, no game server anywhere.

Connection options (STUN / TURN)

STUN alone connects most home networks. If a friend is behind a strict/symmetric NAT and cannot join, add a TURN server (e.g. your own coturn) — traffic then relays through it.
