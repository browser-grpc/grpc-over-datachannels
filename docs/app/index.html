gRPC over WebRTC DataChannels — stub generator

Upload or edit .proto schemas, pick languages, download a zip of generated gRPC-over-DataChannel stubs plus the dependency-free runtimes. The generated JavaScript client runs in the browser on the native RTCDataChannel; other languages run natively or in the browser as Wasm. Everything — schema compilation included — runs in this page; no server sees your schemas, and there is no grpc-web proxy anywhere in the path.

New here? Run your first RPC

One click: this page generates the Echo client from the bundled schema, serves it in-page over a loopback DataChannel pair (the same transport a real RTCDataChannel plugs into), and runs unary + streaming calls. No server, nothing leaves the tab.

Takes a few seconds the first time.
